# Kimi 介绍

## Kimi 是什么？

Kimi 是由月之暗面（Moonshot AI）推出的 AI 助手。用户可以通过自然语言与它交流，让它协助处理信息、写作、学习和编程等任务。

## Kimi 有哪些主要功能？

- **问答与学习**：解释概念、整理思路，并辅助学习和调研。
- **阅读与总结**：帮助梳理长篇文本或用户提供的文件，提取重点并回答相关问题。
- **写作与翻译**：协助撰写、润色、改写和翻译文本。
- **编程辅助**：帮助理解代码、分析问题和生成代码示例。
- **信息整理**：根据用户提供的资料，提取要点、分类或整理成结构化内容。

具体可用功能可能因产品版本、使用入口和账号情况而异，请以 Kimi 当前界面和官方说明为准。

## 如何使用 Kimi？

打开 Kimi 的官方网站或客户端，按照页面提示登录，然后在对话框中输入问题或任务。描述目标、背景和期望的输出格式，可以帮助 Kimi 给出更有针对性的回答。如果当前界面支持文件上传，也可以上传文件并围绕其内容提问。

## Kimi Code 是什么？

Kimi Code 面向编程场景，提供可用于编程工具和工作流的模型服务。本示例使用 Kimi Code 的 Anthropic 兼容接口调用模型。可用模型和接入方式请以 [Kimi Code 官方文档](https://www.kimi.com/code/docs/en/kimi-code/models)为准。

## 使用时需要注意什么？

Kimi 生成的内容可能有错误或遗漏。涉及重要决策、专业建议或具体产品政策时，请核对可靠来源。不要在对话或上传的文件中提供密码、验证码或其他不应共享的敏感信息。

会员价格、权益、文件限制等可能变化，请以当前产品界面或官方公告为准。
